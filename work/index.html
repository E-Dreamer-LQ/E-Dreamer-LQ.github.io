易泊车创新项目——仰望 U8 易四方、腾势易三方垂直及平行泊入功能量产

项目内容

a. 主导代码架构重构，完成易四方（U8、U8L）与易三方（腾势 Z9）双平台垂直端头路泊车系统量产交付, 绩效 A; b. 带领小组重构核心算法架构，提升系统鲁棒性与可维护性;

工作内容

  1. 设计基于单轮旋转几何范式的路径规划算法，优化回旋线车头泊入策略，将泊入成功率提升至95% 以上，显著提升狭窄场景下的泊车效率；
  2. 创新性实现易四方泊车与普通 APA 泊车接口的兼容调用，开发侧边侵入动态脱困和二次旋转自适应泊入功能，增强系统鲁棒性；
  3. 主导基于搜索算法的全链单轮旋转路径规划算法研发: a. 首创旋转节点与常规节点的混合拓展机制，构建可视化调试工具链加速开发迭代 b. 设计融合几何约束与运动学特性的多维度启发式 cost 函数、建立离线启发加速节点拓展 c. 开发高效多圆碰撞检测加速，实现复杂场景下的实时路径优化 d. 推动多车型车型垂直断头路功能、侧方车头与车位甩头泊入量产落地 e. 腾势 Z9 项目（2025.05 量产）集成 Foxglove 可视化工具链，提升诊断效率 40%
  4. 关键技术：a. 几何算法；b. 脱困策略；c. 平滑算法；d.vot ha* 算法实现及迭代

仰望 U8 常规 APA 项目

项目内容

a. 主导开发基于 Hybrid A* 的 APA 泊车系统，实现常规场景 90%+ 泊入成功率（绩效评级 B+）; b. 首创断头路泊入算法，达成 85%+ 极端场景泊入成功率;

工作内容

  1. 优化 Hybrid A* 搜索策略，集成正反向混合搜索机制;
  2. 开发基于障碍物分布的 Target Pose 动态偏移算法;
  3. 突破性解决断头路泊车技术难题 + 设计多模态脱困策略（超时优化 + 障碍物自适应）;
  4. 关键技术：a. 搜索算法；b. 脱困；c. 断头路算法；

海豹 2024 车型 APA 量产落地

项目内容

a. 主导开发行业领先的几何范式垂直泊车系统，实现全场景覆盖（量产评分 6.25，绩效评级 A）; b. 带领 3 人团队完成从算法研发到量产落地的全流程交付;

工作内容

广汽 E9 车型 HPA 量产落地项目

项目内容

基于广汽传祺 E9 MPV HPA 泊车功能闭环量产 6 月 sop 和 10 月 ota1.0 交付，升级点：循迹效率提升、泊出性能提升、绕行功能

工作内容

  1. 主导两套几何规划算法（局部 → 全局）向 HA（Hybrid A）的迭代升级，优化出库路径规划逻辑，实现 OTA 1.0 版本出库成功率较 SOP 阶段提升 20%+;
  2. 深度优化 hpa 建图路径优化处理算法流程 (ceres + drop + ha*)，提高循迹性能；
  3. 完善 hpa 循迹 n-point-turn 功能开发，转弯刹停纵向优化，提高循迹效率;
  4. 提出基于定位反馈的曲率动态补偿算法，增强大曲率路径的跟踪性能，横向误差降低 30%；
  5. 设计 APA（自动泊车辅助）泊出算法，融合几何法与 Hybrid A* 搜索，完成 APA→HPA（高阶泊车辅助）的无缝切换与联合调试；
  6. 开发 Lattice Planner 框架下的 HPA 小幅绕行功能，提升狭窄通道场景通过率；

xbrain——无人配送集群小车项目

项目内容

基于数据闭环，目标打造一款场景覆盖度高，可靠性高，成本有充分竞争力的自主出行智能系统，建立自动驾驶集群小车，实现 A 到 B 的自主出行。目前已实现重定位导航、轨迹跟踪、速度规划、绕障。

工作内容

  1. 从 python 到 cpp(ros2) 的环境迁移，设计并建立传感器数据、定位、规划、控制的闭环；
  2. 参与 lane 级导航功能实现，基于 A* 算法的 A 到 B 的最短路径规划；
  3. 负责基于 lqr 和 pure pursuit 算法的融合传感器数据信息避障循迹功能实现；
  4. 负责纵向速度规划，实现入弯慢，出弯快的智能纵向控制；
  5. 基于 lattice 和 costmap 的绕障、变道等功能持续实现中；
  6. 技术涉及：a. 底盘调试；b. 车辆运动学；c. 控制算法；d. 局部规划及运动规划；f. 智能驾驶闭环；

项目成果
